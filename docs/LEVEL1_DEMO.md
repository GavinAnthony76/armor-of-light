# The Desert Ruins: playable Level 1 demo

Branch: levels. Starting GitHub main: e4e4be3f04f32a4ca46595a70887a947303f2e93. Starting test suite and static build passed before editing. The source preserves the approved combat engine, attack timings, hammer animation, parry/reflection, dash, wall movement and double jump.

The default entry point is now the self-contained first-land demo. Begin from the title, read/skip the chapter, traverse all seven sections, fight or pass open-road skirmishes, defeat the Dune Warden, reach the lit beacon, then replay from the completion sheet. Levels shows only this demo. Keyboard, touch and gamepad bindings are retained. The browser demo uses armor-of-light-desert-demo-v1, separate from campaign saves. Restart clears alternate equipment; Continue/checkpoint retry retain it. The campaign adapter remains accessible with ?campaign for integration checks, but the new Level 1 geometry should not be merged into the broader game without migrating old Level 1 run indices/collected motes. Other six land definitions are unchanged.

Seven authored sections: Silent Approach, Broken Aqueduct, Caravan Court, Sunken Archive, Windward Crossing, Beacon Stair and Warden’s Court. Four encounters/checkpoints, safe teaching walls, upper collectible routes, two broken spans with lower catch ledges, a late climb, a broad boss floor and the final beacon. Optional Sunblade drops use the existing enemy reward journal, explicit pickup and rank I–III system. No moving-platform physics, traps or rain were added: this desert pass uses independent cloud drift, two additional architectural depth layers, dust, animated cloth and a beacon flame. Existing illustrated art is retained.

The layout uses the actual movement values (jump speed 800, gravity 2300, horizontal speed 305) rather than changing combat to suit the terrain. Standalone/GitHub Pages and YouTube entry points are built from matching hashes. The surrounding game work by Replit should continue separately; review the levels branch diff before incorporating it.

Validation logs: LEVEL1_TESTS.txt (323 rule/layout assertions, 42 campaign runs, 276 weapon assertions with 28 alternate campaign runs, existing save/action/audio/host/input/traversal/layout checks); LEVEL1_ROUTE_TESTS.txt (24 dedicated checks, both difficulties with hammer or Sunblade III, forced checkpoint retry, restored equipment journal, upper-route jump reach); LEVEL1_BUILD.txt (static, standalone and 15 bundle/reference checks). Simulation playthroughs are not claims of human combat-feel or physical-phone verification.

## Ownership handoff
User confirmed: ChatGPT owns level layouts and encounter design. Replit owns combat, movement, weapons/upgrades, animation, splash/story, music and integration. This branch changes no player, enemy, input, animation, soundtrack or weapon engine files. `desert-demo.ts` and its levels.ts registration are the core design deliverable; the renderer additions provide level-specific depth/cloth/beacon art. The main/UI/WebPlatform edits are demo packaging adapters (single-land menu, isolated save, section objective, demo completion copy); Replit should incorporate those only as appropriate to its current integration. Do not overwrite Replit's shared files wholesale. Shared renderer and UI changes require a reviewed merge. No automatic merge into main is requested.
